# Introduction

### What is Pangolin?

**Pangolin** is a tool used to create detailed and complex steel structural models. It allows users to define elements such as beam haunches, configurable cold-formed sections with stiffeners, and surface loads that are distributed onto beams through load transfer surfaces. Pangolin also supports defining load combinations from individual load cases.

![alt text](img/pangolinreveal-06.png)

Once the model is created, it can be saved for later use or sent directly to **Consteel** for analysis using Consteel’s specialized calculations. The latest version of Pangolin can process analysis and design results from Consteel, including first and second order analysis, buckling analysis, and strength and buckling checks.
