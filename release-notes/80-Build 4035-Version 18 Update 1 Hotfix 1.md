**06-03-2025 	build 4035**


_**Bug fixes:**_

- At some places incorrect texts appeared in the software due to translation problems. The bug has been fixed. 
- In case of analysis on elevated temperature without indirect effects of thermal expansion, the calculation was not executed with the reduced elastic modulus in the combinations with fire. The bug has been fixed.
- The start height of the haunch was missing from documentation. The bug has been fixed. 
- The lip of several library cold-formed section was missing on the graphical interface. The bug has been fixed. 
- Adjustments on linear summation in seismic calculations. 
- Shear filed was not possible to define on welded box section. The bug has been fixed.
- It was not possible to define a plate with coated steel material with Descript. The bug has been fixed.


_**Improvements:**_

- Several Consteel features were added to the list of functions we collect usage statistics about.
- The modification of the section on a large number of bar members has been significantly accelerated.
