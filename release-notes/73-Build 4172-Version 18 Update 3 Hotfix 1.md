**17-06-2025 	build 4172**


_**Bug fixes:**_

- Problem with displaying the end marks has been fixed. 
- Sorting load combinations by values has been temporarily disabled on Load combination dialog due to a bug until final fix.
- Stable length results were not displayed in Section module. The bug has been fixed. 
- Bug in plastic hinge analysis has been fixed. 

_**Modifications:**_

- Frame corner can be placed not only to bar members with continuous end releases but with semi-rigid too. 
- Connection stiffness can be considered in case of frame corner present.
