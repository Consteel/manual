**21-11-2025    build 4446**


**New Consteel version 19**

- FALCON plugin for realistic wind load generation introduced.

- Connection design enhanced with IDEA StatiCa Checkbot export and Fictive Joint.

- New Descript commands added for faster modeling and automation.

- Fire design improvements with galvanizing effects and real intumescent paint data.

- Load Transfer Surfaces can now include slightly offset bar members.

- Eccentric members can be positioned with flexible reference points.

- Tapered built-up members with variable plate thickness supported.

- Model repair tools for correcting geometric errors added.
