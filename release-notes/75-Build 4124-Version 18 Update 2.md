**19-05-2025 	build 4124**


_**Bug fixes:**_

- Hot-rolled rods were transferred as a tube into IDEA StatiCa Connection. The bug has been fixed.
- Handling of through-going beams during load transfer to IDEA StatiCa Connection has been fixed. 
- Improvements were made on load distribution logic to avoid incorrect distributions.
- In certain cases there were problems with modifying LTS-s. The bug has been fixed.
- Display of composite cross-sections in Section module was incorrect. The bug has been fixed.
- Hotkey for Colouring by section (Alt-C) was not working. The bug has been fixed.
- Sorting of models is fixed in Cloud Open dialog.
- Crane load setting were not properly saved. The bug has been fixed.
- .smadsteel files created by Consteel 17 or Axis Converter could not be imported into Consteel 18. The bug has been fixed.
- Adjustments on meteorological surface placement. 
- In some cases when a tension rod was connected to a support, reaction forces appeared in the released direction. The bug has been fixed.

_**Improvements:**_

- Necessity of intumescent painting is now shown on Design result table in case of critical temperature calculations.
- Several improvements and new commands in Descript including shearfield, frame corner, sway imperfection. 
- Aeff added to result documentation of settlement calculation in Consteel Joint.
