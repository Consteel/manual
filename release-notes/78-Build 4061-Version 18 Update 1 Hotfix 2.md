**28-03-2025 	build 4061**


_**Bug fixes:**_

- Bug in bulk material change on Section administration dialog has been fixed. 
- Several errors in IFC and SAF import have been fixed including positioning and section conversion problems.
- Fire load combination generation caused the software to be freezed for a long time in case of huge number of wind load cases. The bug has been fixed. 
- USB net dongle was not recognized by Consteel and so the software did not start with this protection. The bug has been fixed. 
- Character coding error has been fixed in plugin loading.  


_**Modifications:**_

- Lindab library cross sections have been changed according to actual product palette of Lindab.
